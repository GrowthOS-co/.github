# Agentrail

Agentrail reconstructs real agent journeys across your website, docs, APIs, SDKs and MCPs. See your agent task completion rate, exactly where agents break, and what to fix first.

[Website](https://agentrail.co) · [About](https://agentrail.co/about)

## What you see

- **The journey.** Activity across your website, docs, APIs, SDKs, MCPs and tools becomes the task the agent was trying to finish.
- **Where it breaks.** Where agents hesitate, retry, take extra steps, or fail.
- **What to fix first.** Changes across docs, auth, APIs, SDKs and MCPs, checked against real traffic.

## CLI

[agentrail-cli](https://github.com/GrowthOS-co/agentrail-cli) is the Agentrail command line for a terminal or a coding agent.
